Capabilities

Built to actually do things

Every capability below ships in ClarityOS today. Where something needs setup or is still maturing, it says so.

🎙

Voice conversations

Talk with a global hotkey or leave conversation mode on for hands-free back-and-forth. Speech recognition runs through Google, Gnani or Sarvam, and replies are spoken back to you.

Working
🖥

Desktop assistance

Opens applications, manages windows, reads the screen, types and clicks — driven by a local Windows helper you start yourself and can stop instantly with a kill switch.

Working
✨

Intelligent task execution

Breaks a request into milestones, picks the right tools, verifies each result, and replans when something fails. Anything consequential pauses for your explicit approval first.

Working
🌐

Browser automation

An optional Chrome extension lets ClarityOS read page structure, click elements and fill forms. Install it yourself and pair it with a code — nothing connects without that.

Needs the Chrome extension
🔊

Natural speech output

Replies are spoken using the built-in Windows voice with no account or key required. Add a Google Cloud, Gnani or Sarvam key for higher-quality, more natural voices.

Built-in voice by default
🔑

Wake word

Say a wake phrase instead of reaching for a hotkey. This needs a Picovoice access key and its keyword model; without them ClarityOS stays on push-to-talk, which works out of the box.

Needs a Picovoice key
📞

Phone calls

Place outbound calls through a Bolna voice agent and get back the status, transcript and extracted details. Requires a Bolna account, and every call asks you first.

Needs a Bolna account
🧩

Configurable providers

Swap the model, speech engine and voice from one settings page. Keys live in Windows Credential Manager, never in the interface and never in logs.

Working
🔁

Saved workflows

Keep multi-step routines and run them again later. Useful today, and the area we are actively building out — expect it to change.

How it works

Listen. Understand. Act.

Three stages, every single request — and you stay in control at the last one.

STAGE 01

Listen

A hotkey or wake phrase opens the microphone. ClarityOS waits for you to finish speaking, detects the silence, and turns the audio into text — with a fallback engine ready if the first one fails.

STAGE 02

Understand

It reads what is on screen, which app is in front and what you said before, then plans the work as a short list of milestones with a clear success signal for each one.

STAGE 03

Act

It runs the plan with real tools, checks each result, and recovers when something does not work. Anything that spends money, sends a message or changes files stops and asks you first.
